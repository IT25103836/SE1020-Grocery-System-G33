Project Documentation: Online Grocery Order Management System
Project Overview

This is a web-based application developed for the SE1020: Object Oriented Programming module. The system is designed to manage grocery inventory, customer orders, and user authentication using Java and file-based data storage. 
Key Features & Components

Based on the project requirements, the system is divided into 6 major components: 

    User Management: Handling registration and login for Customers and Admins. 

    Product Management: CRUD operations for grocery items (Name, Price, Category). 

    Order Processing: Using a Queue data structure to process customer orders sequentially.

    Inventory Sorting: Implementing Merge Sort to display products by category or price.

    Payment & Billing: Generating invoices and updating transaction logs in .txt files. 

    Admin Dashboard: High-level control over users and stock. 

Technologies Used

    Backend: Java (JSP & Servlets) 

    Frontend: HTML, CSS (Bootstrap), JavaScript 

    Data Storage: File I/O (Read/Write to .txt files) 

    OOP Concepts: Encapsulation, Inheritance, Polymorphism, and Abstraction.
